## Introduction

Ugarit Folio is a powerful page based router designed to simplify routing in Ugarit applications.

## Official Documentation

Documentation for Ugarit Folio can be found on the [Ugarit website](https://ugarit.com/docs/folio).

## Contributing

Thank you for considering contributing to Ugarit Folio! The contribution guide can be found in the [Ugarit documentation](https://ugarit.com/docs/contributions).

## Code of Conduct

In order to ensure that the Ugarit community is welcoming to all, please review and abide by the [Code of Conduct](https://ugarit.com/docs/contributions#code-of-conduct).

## Security Vulnerabilities

Please review [our security policy](https://github.com/ugarit/folio/security/policy) on how to report security vulnerabilities.
